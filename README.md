# netflix-visualization-using-power-bi
 Netflix Movies &amp; TV Shows Dashboard using Power BI Dive into 6,000+ Netflix titles across 100+ countries! This interactive dashboard visualizes genre distribution, content trends by year, top-producing countries, ratings, and more to help uncover what drives global streaming content.

 ## Key Features

- Genre-wise content breakdown
- TV Shows vs Movies distribution
- Rating classification across titles
- Country-wise contribution to Netflix content
- Content trend by release year (1925–2020)

## Tools Used

- Microsoft Power BI
- DAX & Power Query for data transformation.

## Insights from the Project
From your Power BI dashboard, these are the key insights:

Content Volume:

Netflix has 6,169 titles in total (as of data).

68% are Movies, while 32% are TV Shows.

Genre Popularity:

Documentaries, Stand-Up Comedy, and International Dramas top the list.

Over 460 unique genres are represented.

Ratings Breakdown:

Most content is rated TV-MA and TV-14, indicating a mature audience target.

Top Countries:

USA dominates Netflix content creation (2.03K+ titles).

Followed by India, UK, and Japan.

Timeline Analysis:

Content peaked dramatically after 2010.

Netflix started adding content as early as 1925, with a major surge post-2015.

Content Types by Year:

Movies have been consistently added, but TV Shows surged post-2015, showing Netflix’s growing original series investment.
